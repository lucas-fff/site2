# Mundo Pet — Site demonstrativo

## Como abrir
1. Extraia a pasta `mundo_pet_site`.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador. Para uma experiência melhor, use a extensão Live Server.
4. Navegue pelo menu para testar as seis páginas.

## Páginas
- index.html — Início
- produtos.html — Catálogo com pesquisa e filtro
- servicos.html — Serviços e formulário de agendamento demonstrativo
- sobre.html — Sobre a loja
- contato.html — Formulário de contato demonstrativo
- carrinho.html — Carrinho com quantidades, remoção e total

## Tecnologias
HTML5, CSS3 e JavaScript. O carrinho usa localStorage do navegador.
As imagens são carregadas de URLs externas e precisam de conexão com a internet.
Os formulários e a finalização do pedido são demonstrativos; não enviam dados para um servidor nem realizam cobranças.
